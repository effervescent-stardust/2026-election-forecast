Verify the OpenTimestamps receipt

  1. Download both the ZIP and its matching .ots receipt using the links above. Keep the ZIP unchanged.
  2. Open OpenTimestamps, select the receipt, then select the ZIP when prompted.
  3. The verifier checks the file’s fingerprint and timestamp proof. If a receipt is still pending, it must acquire its Bitcoin confirmation before verification can finish.

For command-line verification, use the official OpenTimestamps client. Full independent verification can use your own Bitcoin node.
