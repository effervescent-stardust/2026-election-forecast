2026 U.S. Senate and House forecast — frozen interim snapshot

Forecast cutoff: November 2, 2026, 1:52:08 p.m. Eastern (18:52:08 UTC).
Research was stopped at the user's request before the planned final cutoff.

The reported percentages are probabilities of winning, NOT predicted vote shares.
Senate forecasts cover statewide contests; House forecasts cover districts.
There are no county or precinct forecasts in this publication.

Contents
- index.html: interactive chart presentation
- methods.html: preserved narrative, forecast tables, limitations and external sources
- data/: full-precision race probabilities, chamber distributions and sensitivity tables
- manifest.json: metadata and SHA-256 hashes for every archived file
- PNG figures: static views of the forecast

The source forecast CSV files are byte-for-byte copies of the archived checkpoint.
The public report replaces local download paths with public relative paths and
removes links to internal working-audit attachments that are not part of this
export. Raw third-party reports and documents are not redistributed in this ZIP.
Charts use version-pinned external display libraries; underlying prediction data
are included in the package.

Timestamp verification
Download this unchanged ZIP and its matching .ots receipt from:
https://effervescent-stardust.github.io/2026-election-forecast/verification.html
Use https://opentimestamps.org/ to verify the receipt against the ZIP. The proof
establishes existence of these exact bytes by the attested Bitcoin block time.
It does not establish authorship, forecast accuracy or the earlier self-reported
model cutoff. An initial pending receipt must be upgraded after confirmation.

The receipt, verification page and ZIP's own checksum are distributed outside
the ZIP so confirmation can be recorded without changing this frozen package.
